Usage Metering and Quota Service API (0.1.0)

Download OpenAPI specification:

OpenAPI documentation for the Usage Metering API.

Account-scoped endpoints identify the account from the X-API-Key header; an account identifier is never supplied by the caller. Account creation and operator key recovery use X-Admin-Token.

All request and response bodies are JSON unless the response is 204 No Content. Error responses use {"error":{"code":"...","message":"..."}} and may include details.

Consumption

Usage decisions and idempotent consumption requests.

Decide and record a usage request

A rejection is a normal decision and returns HTTP 200 with accepted: false; rejected requests consume no units. requestId is the account-scoped idempotency key. A retry with the same ID and payload returns the original decision with replayed: true; using the same ID with a different payload returns 409.

Authorizations:
ApiKey
Request Body schema: application/json
required
requestId
required
string [ 1 .. 200 ] characters

Account-scoped idempotency key.

externalId
required
string [ 1 .. 200 ] characters
units
required
integer >= 1
